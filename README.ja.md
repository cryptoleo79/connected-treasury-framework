## このパッケージは何ですか?

Connected Treasury Framework (CTF) の提案、提出準備の整ったガバナンス提案、長期的なプロトコル更新の概要、そして誰もが数字を自分で検証できるツールをまとめた6つのドキュメントです。

CTFは単一の提案ではありません。すでにコミュニティの支持を得ている要素(Leios型の透明性、Snek型のローン構造、Foundation型の分散投資)と、6ヶ月前には存在しなかった本番稼働中のCardanoインフラ(Pythオラクルフィード、USDCx Tier 1ステーブルコイン)を組み合わせた、一貫したモデルです。

## この順序で読んでください

このパッケージは順番に読むように設計されています。

### 1. `docs/ja/01_report.md` — 基礎ドキュメント
最初に読んでください。問題(財務の侵食)、データ(今週のガバナンス投票、過去の残高/ドル建て価値、ランウェイ予測)、そしてフレームワーク(5つの構成要素、現行提案との比較、実装フェーズ)を確立します。所要時間約12分。

### 2. `docs/ja/02_proposal.md` — 提出準備の整ったガバナンス提案
Leiosテンプレートに従ったPhase 1パイロット提案。**終了時点で財務にプラスの効果**(+0.9M ADA)が出るように設計されています。実際の要求は50M ADA:48M ADAは返済可能な委任元本、2M ADAは運営予算。所要時間約4分。

### 2b. `docs/ja/02b_proposal_lite.md` — フットインドアバリアント
パスしやすいように設計された、より小規模(10M ADA)のバリアント。Phase 1が大きすぎる場合の最初の提出用。所要時間約4分。

### 3. `docs/ja/03_cip.md` — 長期的なプロトコル更新
プロトコルレベルの財務ステーキングと台帳レベルでの強制的な議決権中立化に関するCIP概要。これは構造的な変更で、財務全体で年間約6,500万ADAを生み出します。所要時間約7分。

### 4. `index.html` — インタラクティブツール
4つのスライダー(利回り、支出上限、ローン返済率、戦略的準備金%)で、リアルタイムのランウェイ予測を「何もしない」ベースラインと比較できるスタンドアロンWebページ。日本語/英語切替対応。

### 5. `docs/ja/05_objections.md` — 敵対的レビュー防御
あらゆる反対意見への先制的な回答:市場への影響、中央集権化への懸念、利回りの仮定への懐疑、「すでにこれは存在する」、Hoskinsonとの関連、憲法的問題、プロセスの異議、そして「とにかく信用できない」立場。所要時間約12分。

### 6. `docs/ja/06_hostile_review.md` — 単一視点の批判
懐疑的なDRepの視点からの、提案に対する一貫した攻撃。複数の懸念ではなく、フォーラムで一つの説得力のある「反対」議論がどのように見えるかを示します。

## 過去6ヶ月で変わったこと

過去6ヶ月でCardanoの2つの重要なインフラがライブになりました。それ以前のフレームワークは理論的でしたが、現在は実行可能です。

**Pyth Network (2025年末ライブ)** — 125以上の機関級パブリッシャーからのサブ100msのプルベースオラクルフィード。仮想通貨、株式、外国為替、商品、ETFをカバー。PentadのCritical Integrationsプログラムの最初の成果。

**USDCx (2026年2月27日ライブ)** — CircleがxReserveインフラを通じて発行する、Cardanoネイティブの最初のTier 1ステーブルコイン。USDCで1:1バック、CircleのCCTPを通じてクロスチェーン対応。リリース時点で1,500万USDCx以上が発行されました。

**CTFにとっての意義:** 戦略的準備金(フレームワークのコンポーネント6.2)は最もリスクの高い部分でした。実験的合成資産または資金の管理に依存していました。USDCxはこれをCardanoネイティブのCircle発行・監査済み・完全裏付けされたステーブルコインに置き換えます。ペッグ離脱検出問題はPythの機関級オラクルフィードによって解決されます。最も批判された2つのコンポーネントが、本番稼働中のインフラに支えられるようになりました。

## 読まない人のためのTL;DR

- Cardano財務は利回りゼロで16.21億ADAを保有しています。
- ドル建て価値は2024年末のピーク($2.0B → $389M)から約80%下落しました — 単一資産エクスポージャーが原因。
- 現在の年350M ADAのバーンレートでは、財務は2033年頃に枯渇します。
- Cardano Foundationはすでに自社の財務を51.6% ADA / 25.5% BTC / 22.9%現金に多角化し、ADA一辺倒のポートフォリオを上回るパフォーマンスを示しています。
- Connected Treasury Frameworkは以下を提案します:財務をステーキングし、小規模な構造化されたUSDCx + BTC準備金を保有し、グラントではなくローンをデフォルトとし、年間支出に上限を設け、Pythを基にしたオンチェーンデータですべてを公開報告。
- Phase 1パイロット:18ヶ月で50M ADA、終了時純額+0.9M ADA。Phase 2:ハードフォークによる完全な財務ステーキングのプロトコル更新。
- これはHoskinsonの1億ドル提案ではありません。Foundationの5,000万ドル流動性ファンドでもありません。両方を補完し、どちらよりも構造的に厳格です。

## 命名について

このパッケージでは一貫して "Connected Treasury Framework (CTF)" を使用しています。これは意図的に:

- 哲学的ではなく説明的
- 特定のプロジェクト、オペレーター、創設組織と関連しない
- 明確で機能に根ざした名前というCardanoの慣習と互換性がある

「接続が生成的な力である」という原則(財務はネットワーク自体のインフラと「接続する」ことで稼ぐべきであり、受動的に座っていてはならないというフレームワークの中核的哲学的主張)の知的系譜は、Cardanoのオペレーターファーストの独立インフラ作業に影響を与えた日本の文化的概念(繋ぎ / 結び)にさかのぼります。その系譜は`01_report.md`の謝辞で認められていますが、提案を生態系中立に保つために、フレームワーク名自体には埋め込まれていません。
